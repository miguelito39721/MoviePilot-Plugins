# 音乐标签刮削（MusicTagScraper）

按 `music-tag-web` 的思路为 MoviePilot 增加音乐刮削能力：扫描本地音乐目录，多源补全标签、歌词与封面。
默认**只补空缺**，不重命名、不移动、不删除文件，适合配合 Navidrome / Emby / 飞牛音乐使用。

## 功能

- **多源元数据**：豆瓣音乐 → MusicBrainz → TheAudioDB 依次回退，补标题、艺人、专辑、专辑艺人、年份、曲序、流派
- **多源歌词**：使用宿主已启用的歌词模块（LRCLIB、AMLL 等）写入同名 `.lrc`，可选写入 `[ti:]/[ar:]/[al:]` 头部元信息
- **封面补齐**：优先嵌入在线封面（Cover Art Archive / 豆瓣），同时保留原图
- **专辑目录封面**：为没有图片的专辑目录补写 `cover.jpg` / `folder.jpg`，在线封面优先，缺失时从音频内嵌封面提取，供 Navidrome / 飞牛音乐 / Emby 读取
- **只补空缺 / 覆盖**：默认只写缺失字段；开启覆盖后按来源结果重写
- **试跑预览 + 勾选执行**：扫描并匹配，列出缺失项、目录封面状态与命中专辑，可只处理勾选的音频
- **失败清单**：失败条目单独记账，支持单条重试或一键全部重试；支持清空记录
- **首页仪表板**：展示今日更新、歌词、目录封面与失败数，运行中显示进度
- **定时补全**：可配置每 N 小时自动扫描一次
- **侧栏整页**：可在主界面侧栏打开完整操作页

## 工作原理

1. 按配置目录递归扫描音频文件（flac/wav/mp3/m4a/ape/aiff/ogg/opus/wma/dsf/dff/wv）
2. 读取现有标签，判断缺失字段（标题/艺人/专辑/年份/曲序/歌词）
3. 以「专辑名 + 艺人」为键查询元数据来源，按标题相似度打分，低于阈值不写入
4. 用宿主 `AudioMetadataHelper` 原子写标签与封面（复制成功后替换，写坏不影响原文件）
5. 查询歌词候选，写入同名 `.lrc`（已有歌词时默认不覆盖；可选补写 LRC 头部元信息）
6. 目录没有 cover/folder 图片时写入专辑封面文件，优先在线封面，其次读取音频内嵌封面
7. 记录文件指纹，未变更的文件下次自动跳过；目录封面被删除后会重新补写

## 配置项

| 配置 | 说明 |
| --- | --- |
| 启用插件 | 总开关 |
| 显示侧栏入口 | 是否在左侧导航显示整页入口 |
| 音乐目录 | 每行一个目录，递归扫描 |
| 排除目录 | 每行一个目录，常见为 MV / 试听目录 |
| 元数据来源 | 豆瓣音乐 / MusicBrainz / TheAudioDB，按勾选顺序尝试 |
| 补全音频标签 | 是否写入标签 |
| 补齐内嵌封面 | 是否下载并写入音频内嵌封面 |
| 写专辑目录封面 | 是否为专辑目录补写封面文件 |
| 目录封面文件名 | `cover.jpg` / `folder.jpg`，可多选 |
| 写入歌词（.lrc） | 是否写同名歌词 |
| 歌词写入 LRC 头部信息 | 是否在歌词开头写 `[ti:][ar:][al:][by:]` |
| 覆盖已有标签 | 关闭时只补空缺 |
| 覆盖已有歌词 | 关闭时已有 `.lrc` 不覆盖 |
| 匹配阈值 | 标题相似度阈值（默认 0.62） |
| 并发 | 同时处理的音频数（1-8） |
| 单次最多处理音频数 | 单轮上限，避免一次扫全库 |
| 定时补全间隔 | 小时，0 表示不自动运行 |
| 完成后通知 | 批次结束后发送通知 |
| 首页显示仪表板 | 是否在首页显示处理统计卡片 |

## 前置条件

- MoviePilot V3（`app.sdk.plugin._PluginBase`）
- 已启用至少一个音乐元数据模块（豆瓣 / MusicBrainz / TheAudioDB）
- 需要歌词时启用 LRCLIB 或 AMLL 模块
- 音频文件对 MoviePilot 容器可读写

## 安装

本地插件源（`PLUGIN_LOCAL_REPO_PATHS`）已包含本插件时，在「插件」页面刷新市场后安装即可。

## 版本

- v1.2.1：目录封面不会写入配置的音乐根目录（例如 `/vol2/1000/music` 根下的散装单曲），避免在音乐库根生成 `cover.jpg`。
- v1.2.0：新增专辑目录封面（`cover.jpg` / `folder.jpg`，在线封面优先、音频内嵌封面兜底、不覆盖已有图片）；试跑结果支持勾选执行；歌词写入 LRC 头部元信息；失败条目支持单条重试；首页新增处理仪表板与今日统计。
- v1.0.1：修正图标地址；支持从目录名推断专辑与艺人，自动清理曲名中的曲序号与方括号。
- v1.0.0：初始版本，支持多源标签补全、歌词写入、封面补齐、试跑预览、失败重试与定时补全。
