# 站点保种统计（SeedStats）

MoviePilot V3 插件：按 tracker 汇总各站点在本机下载器中的做种情况，并合并 MoviePilot「站点数据」里的账户信息。

## 功能

- **按站点统计做种**：读取已配置下载器中的全部任务，按任务的 tracker 归属到站点，统计每个站点的
  `任务数 / 做种 / 暂停 / 其他 / 其中辅种任务数`。
- **合并账户信息**：从 MoviePilot 的「站点数据」读取 `上传 / 下载 / 分享率 / 等级 / 魔力 / 数据时间`。
- **时魔估算**：`时魔*` 为根据相邻两次站点数据快照的**魔力增量 ÷ 时间**估算（**不是站点官方时魔**），
  用于观察实际魔力增长速度。
- **展示入口**：
  - 插件详情页：统计卡片 + 「做种数 Top 12」横向柱状图 + 「辅种占比」饼图 + 完整明细表
  - 首页仪表板：做种中 / 辅种任务 / 总上传 / 总下载 卡片 + 做种柱状图（可在首页仪表板编辑模式中启用）
- **只读安全**：不会修改、暂停或删除任何任务；插件不申请任何额外 API。

## 工作原理

- 统计在**后台线程定时执行并缓存**（默认 60 分钟，可在配置中改为 5 分钟以上），
  页面与仪表板只读取缓存，因此打开即秒出，不会因为统计耗时拖慢 MoviePilot 的 Web 界面。
  > 提示：MoviePilot 只有一个 API worker，插件页面/仪表板接口中直接做重活会导致整个 Web 界面卡死。
- 读取下载器任务时优先使用 Transmission 原生接口的轻量字段（更快），失败时自动回退到通用接口；
  qBittorrent 等下载器走通用接口（速度略慢，功能一致）。
- 站点归属：tracker 域名 → MoviePilot 站点名（含域名前缀兜底），未匹配到的站点会单独列出。

## 配置项

| 配置 | 说明 |
| --- | --- |
| 启用插件 | 总开关 |
| 显示首页仪表板 | 是否在首页仪表板中提供卡片 |
| 刷新间隔(分钟) | 后台统计周期，默认 60，最小 5 |
| 统计的下载器 | 多选，留空表示统计所有已启用下载器 |

保存配置后会立即重新统计一次。

## 安装

在 MoviePilot 的「设置 → 插件市场地址」中加入本仓库地址：

```
https://github.com/miguelito39721/MoviePilot-Plugins
```

随后在「插件」页面刷新市场，搜索「站点保种统计」即可安装。
